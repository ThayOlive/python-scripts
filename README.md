Script Web Scraping:
pasta: web_scraping
Um script que acessa uma url e baixa arquivos pdfs com um filtro específico. 

Script Transforma dados:
pasta: transforma_dados
Esse script extrai dados de uma tabela em formato pdf, e salva em formato csv, além de fazer algumas alterações específicas em algumas colunas.

Querys SQL:
pasta: banco_de_dados
Cria tabelas compatíveis com arquivos csv importados, importa dados do arquivo csv para um banco de dados PostgreSQL, e faz consultas específicas.
